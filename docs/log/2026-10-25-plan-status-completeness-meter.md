# 2026-10-25 · DeepSeek · completeness meter on the today page

Add a "Project completeness" meter to the generated "MorpheOS — today" page. It counts each
doc-20 task's status from its heading (`### S7 · ... · open`) and shows the percentage of the
approved plan that is done (done ÷ (done + open + in progress + blocked)); `proposed` ideas are
listed but not counted in the denominator. The page is regenerated by CI on every push to main,
so the meter re-syncs itself as tasks are marked done.
