## What this branch is

`integrate/1.0` = `main` + the two changes 1.0 means, so the stick can be written **now** instead of after
gates that have been flaking all night:

- **the boot sound** (the work of #163): `alsa-utils`, the theme WAV, and `morph-boot-sound.service`,
  which is the mechanism that works on this image — ALSA directly, because PipeWire has no units and
  WirePlumber cannot publish a default sink without a D-Bus session (both measured on the machine);
- **the identity** (the work of #173): `os-release`, `lsb-release` and `issue.net` say **MorpheOS 1.0**,
  with `ID_LIKE="debian ubuntu"` so apt and packaging keep working, and the build fails if `NAME` is not
  `MorpheOS`.

The PRs still merge on their own merits; this branch exists so the artefact matches the product name the
moment the name exists.

## Verified before it is flashed

The chain refuses to write unless the decompressed artefact contains `NAME="MorpheOS"`, the
`AuthorizedKeysCommand` line, and `morph-boot-sound` — read out of the image, not out of the repo.
