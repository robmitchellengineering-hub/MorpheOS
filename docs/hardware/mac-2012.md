# mac-2012 — hardware report (E6)

> Written from the machine's own boot report (`/efi/morpheos-report/00N-…/summary.txt`, `lspci.txt`) and from
> what was measured over SSH on 2026-11-04. "Detected" is not "works" — where a thing was only detected, it says
> so. No MAC address appears here: the repository is public.

## Machine

Apple **MacBookPro9,1** (2012 15-inch MacBook Pro), Intel **i7-3615QM** (8 threads), **7.7 GiB** RAM, two
graphics controllers (Intel HD 4000 and an NVIDIA GT 650M), Broadcom Ethernet and Wi-Fi. Booted repeatedly from
the `plain` USB stick through 2026-11-04 and used as the reference machine for the robmesh-node work
([doc 26](../26-robmesh-node.md)).

## Boot path

USB stick, UEFI, `morph.slot=a`, Secure Boot not involved. Every boot reached `MORPHEOS CONSOLE READY` with
`{"booted":"a","default":"a","phase":"committed"}` — the slot is committed, no trial, no fallback. Boots that
followed a device change in the VM (a TPM or a USB disk) dropped to the UEFI shell; that is a property of the VM's
firmware, not of this machine.

## Display

Two controllers are present and the report names both:

```
00:02.0 VGA compatible controller: Intel Corporation 3rd Gen Core processor Graphics Controller [8086:0166]
01:00.0 VGA compatible controller: NVIDIA Corporation GK107M [GeForce GT 650M Mac Edition] [10de:0fd5]
```

The Intel controller drives the display (`i915`); the compositor draws through it. The **NVIDIA controller has no
driver bound**, so there is no 3D acceleration and the machine behaves as Intel-only — which is the intended
behaviour for this generation and not a fault. Not exercised: external display, resolution change.

## Keyboard

`Apple Inc. Apple Internal Keyboard / Trackpad` is detected as an input device. The console autologin completes
(that is what prints `MORPHEOS CONSOLE READY`), so the console is usable; the internal keyboard was **not exercised
inside the shell** on this machine — that claim would need someone typing.

## Touchpad

`bcm5974` is bound and the trackpad is part of the same input device above. Detected; **not exercised** — no
pointer test was run, so "the touchpad works" is not claimed.

## Wi-Fi

Broadcom **BCM4331** `[14e4:4331]`. **Works** — measured, not inferred: the machine associated with a WPA network,
resolved DNS, and reached the internet (`curl` to `github.com` and `static.rust-lang.org` returned 200, and it
joined the tailnet at `100.108.12.111`). This is the strongest Wi-Fi claim in the project so far because someone
actually used it.

## Wired

Broadcom **BCM57765** Gigabit Ethernet `[14e4:16b4]`, interface `enp2s0f0` — **DOWN**, no cable during any boot
recorded here. Present; not tested.

## Sound

Cirrus **CS4206** analog codec. **Works**, and it cost a real fix: `pipewire`, `pipewire-pulse` and `wireplumber`
all ship `ConditionUser=!root`, and this image autologins **as root**, so systemd skipped the audio stack on every
boot and nothing could make a sound. Clearing that condition (three user-unit drop-ins) produced audio — Rob heard
the theme. Default sink volume was 0.40 and had to be raised. Details in
[doc 26](../26-robmesh-node.md) and the 2026-11-04 log entry.

## Firmware missing

```
FIRMWARE THE KERNEL ASKED FOR AND DID NOT FIND
  none
```

Nothing missing on this machine — worth recording, because a 2012 Mac is the class of machine where firmware is
usually the first problem.

## Boot history

Two boots recorded, both `degraded`, both for the same reason:

```
{"state":"degraded","status":{"booted":"a","default":"a","phase":"committed"},"decision":{"action":"none"}}
{"state":"degraded","status":{"booted":"a","default":"a","phase":"committed"},"decision":{"action":"none"}}
morph-boot-check: failed unit: tailscaled.service
```

The causes were both fixed on 2026-11-04: `tailscaled`'s unit asked for a cache directory on a read-only root, and
`apt-daily*` fails permanently on an immutable system, which is what kept the state `degraded` even when everything
else was healthy. A machine that always reports a problem is a machine whose reports stop being read.

## Tasks

- **E11** (blocked): the session runs as root, which is why the audio units needed condition-clearing and why
  `/root`, `/var` and `/etc` are unusable at runtime. A non-root session is the real fix.
- **apt timers masked** (done 2026-11-04): `apt-daily*` cannot work on a read-only root and made every boot
  degraded. `morph-autoupdate` is the update mechanism.
- **Touchpad and internal keyboard inside the shell: unverified.** A pointer test would close it; nothing about
  this machine's report suggests a problem.
- **NVIDIA GPU has no driver**: intended for this generation, recorded so nobody spends a night on it.
- **Rob's E6 decision** (the reference laptop, note 6) is his, not the builder's. This machine was used as the
  reference for the node work on 2026-11-04; that is a fact, not the decision.
