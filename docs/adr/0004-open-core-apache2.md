# 0004 · Open core, Apache-2.0

**Status:** Accepted, 2026-10-10

## Decision
- The MorpheOS userland is licensed **Apache-2.0** (patent grant, enterprise-friendly).
- Free and open: everything needed to make *your own* devices unbreakable (the whole OS,
  heal engine, Phoenix to your own devices, the self-hosted mesh, specs).
- Paid: the fleet console beyond N devices, hosted relay, hosted encrypted backup,
  premium cloud AI, Morpheus-powered build features, support and OEM licensing.

## Consequences
- Paid services live outside this repository.
- Code brought over from Morpheus (same owner) becomes Apache-2.0 here. Decide file
  by file (doc 17).
